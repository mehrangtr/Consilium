# پروژهٔ `Consilium` — نقطهٔ ادامهٔ مرحلهٔ یک

مرحلهٔ صفر پذیرفته شده و کد پایهٔ برنامه در `src/consilium` ساخته شده است. مرحلهٔ یک برای دریافت شاهد اجرای ویندوز باز می‌ماند. مرجع وضعیت `PROGRESS.json` و نمای مشتق آن در `evidence/navigation` است.

دامنهٔ نسخهٔ اول: ویندوز و لینوکس، پنج سرویس `ChatGPT`، `Claude`، `Gemini`، `DeepSeek` و `Qwen`، اتصال‌های `API` و `BROWSER` طبق قابلیت واقعی، همراه مسیر `MANUAL`. بودجهٔ فعلی آزمون صفر است. مدل، حساب و قابلیت واقعی اتصال‌ها هنوز تأیید نشده‌اند؛ برنامهٔ فعلی فقط اتصال ساختگی دارد.

در مرحلهٔ یک، قراردادهای دادهٔ سختگیرانه، شناسه‌های جدا، ورودی تثبیت‌شده و هش آن، قرارداد قابلیت اتصال و اتصال ساختگی ساخته شده‌اند. محتوای عمومی از کلید، کوکی، رمز و مسیر خصوصی جدا است. طرح داده قواعد دامنه و دوام پایگاه را اثبات نمی‌کند. شورا، دفتر عملیات ماندگار، مرورگر واقعی و بازیابی کامل در مراحل بعد ساخته می‌شوند. هیچ‌یک از ۳۰ خواستهٔ محصول به‌عنوان پذیرش اجرایی کامل علامت نخورده است.

پس از آماده‌سازی `Python 3.12` و نصب `requirements.lock`:

```text
python tools/qualityctl.py navigation
python tools/check.py
python tools/run_consilium.py mock --question "یک سؤال آزمایشی"
```

دمو فقط نتیجهٔ اتصال ساختگی را نشان می‌دهد؛ یک شورای کامل یا بحث پایان‌یافته نیست. برای آزمون ابهام ارسال:

```text
python tools/run_consilium.py mock --question "آزمون" --mode BROWSER --scenario timeout_after_send
```

کد خروج `2` برای این سناریو عمدی است: نتیجهٔ تحویل نامعلوم، پاسخ کامل محسوب نمی‌شود. هیچ درخواست خارجی ارسال نمی‌شود.

راهنمای کامل محیط و اجرای ویندوز: `docs/RUNBOOK_FA.md`. علت تصمیم‌ها: `docs/decisions`. گزارش و دستور دقیق ادامه: `START_HERE_FA.md` و `PROGRESS.json.resume`.

آزمون ویندوز به کاربر واگذار نمی‌شود. مسیر اجرای خودکار دو محیط و جمع‌آوری شواهد در `docs/AUTOMATED_WINDOWS_FA.md` آماده است. این پیکربندی هنوز شاهد اجرای ویندوز نیست؛ بارگذاری در مخزن عمومی متصل به اجازهٔ انتشار بسته نیاز دارد.

مرجع حاکمیت در `baseline` بدون تغییر است. نقشهٔ `ROADMAP.json` ترتیب مرحله‌ها را کنترل می‌کند؛ اسناد نقشه و مقایسه، تحقق اجرایی آن مرحله‌ها را ادعا نمی‌کنند. گزارش کنترل آرشیو فقط مسیر و هش را بررسی می‌کند؛ برای بازتولید باید در پوشهٔ تازه کد و آزمون‌ها اجرا شوند.
