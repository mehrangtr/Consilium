# نقطهٔ ادامهٔ فعلی

مرحله‌های `P00` تا `P03` پذیرفته شده‌اند. پذیرش نهایی `P03` در `PROGRESS.json` به رسید و تصویر ثابت بازبینی ارجاع دارد؛ پذیرش نخستِ دارای جمع زمان ناقص در تاریخچه محفوظ و پیش از اجرای مرحلهٔ بعد جایگزین شده است. شاهد زندهٔ خروج کنترل‌شده با انقضای طبیعی یکی نیست. تلاش با تحویل نامعلوم دوباره ارسال نمی‌شود؛ شواهد خام خصوصی‌اند.

کار جاری `P04-001` است: طراحی قرارداد و ماتریس آزمون آماده، کد و آزمون اجرایی هنوز آغاز نشده‌اند. اقدام دقیق و معیار پایان در `PROGRESS.json:resume` است. برای این کار آفلاین ورود لازم نیست. مرحله‌های `P05` تا `P16` کار آینده و مسدودند؛ تحقق کامل محصول هنوز تأیید نشده است.

فرمان شروع:

```sh
python tools/qualityctl.py status
python tools/qualityctl.py navigation --check
python tools/check.py
```

منبع تست‌شده و هویت گزارش هر دو محیط در `HANDOFF.json` و پذیرش `P03` ثبت می‌شوند. تغییر منبع یا شکست واقعی، آزمون تازه می‌خواهد؛ انتظار بی‌مهلت یا تکرار ارسالِ نامعلوم مجاز نیست. کمک کاربر برای اجرای ویندوز لازم نیست؛ مسئولیت اجرای بومی با دستیار می‌ماند.
